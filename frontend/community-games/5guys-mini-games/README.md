# 5Guys Arcade - Bộ 5 Mini-Game Siêu Tốc

Bộ sưu tập 5 trò chơi ngắn gọn, chơi xong lẹ được viết hoàn toàn bằng HTML5, CSS và JavaScript thuần (không cần cài đặt thư viện).

## Danh sách trò chơi
1. **Rút Dao Đúng Lúc (`games/duel.html`)**: Game phản xạ 5–10 giây/ván.
2. **Bấm Nút Đỏ (`games/dont-press.html`)**: Game troll tương tác 2–3 phút phá đảo.
3. **Cắt Dây Bom (`games/snip.html`)**: Game giải đố logic 5 giây/màn.
4. **Đỗ Xe Bão Táp (`games/park.html`)**: Game căn thời gian 1 nút bấm 3 giây/màn.
5. **Ném Giấy Vào Sọt (`games/wind-toss.html`)**: Game vật lý căn hướng gió dưới 1 phút.

## Cách chạy
- Giải nén file `.zip`.
- Mở file `index.html` bằng bất kỳ trình duyệt web nào (Chrome, Edge, Firefox, Safari...) để chọn và chơi game.
